## 博客内容放在哪里？

所有笔记都在仓库的 `src/content/notes/` 目录下。每个 `.md` 文件对应一篇文章，文件名会成为文章链接的一部分。

建议使用简短的英文文件名，例如 `my-first-note.md`，发布后尽量不要修改文件名，以免旧链接失效。

## 新建一篇笔记

在 `src/content/notes/` 下新增文件，并在开头填写信息：

```yaml
---
title: 我的第一篇笔记
description: 用一句话介绍这篇笔记的主要内容。
date: 2026-03-09
category: 编程实践
tags: [Python, 学习]
draft: false
example: false
---
```

日期请改为你的实际写作日期。正文紧接在第二条 `---` 后，用 Markdown 编写。

### 分类和标签

`category` 决定首页左侧分类，新增分类名会自动出现在列表中，不需要修改代码。`tags` 用于补充主题，支持首页搜索和阅读页点击查询。

### 草稿和示例

设置 `draft: true` 的笔记不会生成公开页面，也不会被首页搜索到。`example: true` 只用于标注示例文章，自己的笔记可以删除这一行。

## 写出清晰的文章结构

```markdown
## 我遇到的问题
描述背景。

## 解决方法
给出步骤和代码。

### 注意事项
补充边界条件。

## 总结
记录下一次可以直接复用的结论。
```

文章标题已经由页面生成，正文建议从二级标题 `##` 开始。二级和三级标题会自动进入右侧目录。

## 发布到线上

GitHub Pages 完成首次配置后，将修改提交到 `main` 分支，GitHub Actions 就会自动构建和发布。

你也可以直接在 GitHub 网页上操作：打开笔记目录，选择 **Add file → Create new file**，填入文件名和内容后提交。

详细的部署步骤和本地预览命令，见仓库根目录的 `README.md`。
